# Changelog

Release notes for the Android build published on [Zapstore](https://zapstore.dev).
`zsp` reads the section matching the version being published, so keep the
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) heading format.

The web app at <https://www.boostmebitch.com> ships continuously and is not
versioned here — this file tracks the Android releases cut from git tags.

## [0.1.0]

First Android release: a Trusted Web Activity around www.boostmebitch.com.

- Search, play and boost Podcasting 2.0 shows over Lightning.
- Boost-all across a music episode's tracks, and streaming sats.
- Sign in with Amber (NIP-55), a NIP-46 bunker, NIP-07 or a generated key.
- Live Nostr streams with chat, and boosts sent as NIP-57 zaps.
